# 🏋️‍♂️ MuscleUp

**MuscleUp** is a minimal and modern e-commerce web application built using **Spring Boot** and **Thymeleaf**. It allows users to browse fitness products, add them to their cart, and place cash-on-delivery orders with a smooth checkout experience.

---

## 🚀 Features

* User login and session management
* Product listing with category filtering and search
* Shopping cart with add/remove functionality
* Checkout page with address input and price summary
* Order confirmation and order history
* Responsive design using a clean and modern color palette

---

## 🧩 Tech Stack

**Backend:** Spring Boot, Spring MVC, Spring Data JPA, Hibernate
**Frontend:** Thymeleaf, HTML5, CSS3, Bootstrap
**Database:** MySQL
**Tools:** IntelliJ IDEA / VS Code, Git, GitHub, HeidiSQL

## ⚙️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/MuscleUp.git
   ```
2. Open the project in your IDE (IntelliJ / VS Code).
3. Update the MySQL credentials in `application.properties`.
4. Run the application:

   ```bash
   mvn spring-boot:run
   ```
5. Access the app at `http://localhost:8080/`
